## Estructura de oferta (los 3 escalones para cerrar)

| Escalón | Qué incluye | Objetivo |
|---|---|---|
| **1. El anzuelo (gratis)** | Template ya hecho con la marca del salón | Derribar el "no" inicial |
| **2. La web (pago único + hosting)** | Montaje online, dominio, mobile, reservas | Primer ingreso + entrás como "su sistema" |
| **3. Asesoría + sistemas (mensual)** | Automatizaciones, SEO, panel, soporte | **Ingreso recurrente** — el negocio real |

**Lógica:** el template gratis abre la puerta → la web es el primer sí → la **asesoría mensual de sistemas** (bot, recordatorios, reactivación, SEO) es lo recurrente. Cada carencia detectada en la asesoría = una automatización que vendés después.
