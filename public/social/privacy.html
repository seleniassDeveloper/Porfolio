Social Publishing Platform

Privacy Policy

Operated by Selenia Sanchez · Effective 21 October 2026 · This page is public and does not require an account.

Social Publishing Platform is a personal, private tool operated by Selenia Sanchez. It is used only by the operator to connect and manage her own social media accounts. It is not offered to the public, does not accept public registration, is not sold, and has no subscriptions, billing, or commercial plans.

This policy explains what data the tool processes when the operator connects accounts and schedules or publishes content. Contact: ssseleniasanchez@gmail.com.

What the tool does

The tool lets the operator connect her own accounts on networks such as Instagram, Facebook, TikTok, LinkedIn, and YouTube through each network's official OAuth flow, and create, schedule, and publish content through those networks' official APIs. It includes a calendar, scheduled publishing, and a media library. Connections can be disconnected at any time. The tool never asks for or stores social network passwords.

Data the tool processes

  • Operator sign-in: the operator's email address, optional display name, and a password stored only as a salted hash (scrypt). There is no public user directory and no open registration.
  • Sign-in sessions: a hash of the session token, the IP address and browser (user agent) used, and dates. They are deleted when the session expires or the operator signs out.
  • Connected social accounts: the identifiers each network provides through OAuth (for example an account ID, username or display name, profile picture URL, account type, and the permissions granted).
  • Authorizations (tokens): access and refresh tokens issued by each network. They are encrypted with AES-256-GCM before being stored, are never shown in the browser, and are erased when the account is disconnected or data is deleted.
  • Content and publishing: the text, schedule, target accounts, and attached media of each post, plus the result returned by the network (post ID and URL).
  • Media library: if the operator uploads files, the tool stores metadata (name, type, size, dimensions, duration, tags, folder, and alt text). Files are stored in object storage configured by the operator, not in the application database. Preview access uses time-limited signed URLs.
  • Network notifications: events a network sends to the tool (for example, that an authorization was revoked).
  • Audit log: security-relevant actions (connections, disconnections, deletions) with internal identifiers, dates, the network involved, and the permissions granted. It does not contain tokens, emails, names, usernames, or network identifiers.

TikTok

When the operator connects a TikTok account, the tool uses TikTok Login Kit and the Content Posting API. It requests:

  • user.info.basic — TikTok open ID, display name, and avatar, so the tool can show which account is connected.
  • video.publish — to publish videos or photos the operator creates or schedules (Direct Post).
  • video.upload — to upload content to the operator's TikTok inbox or drafts when that flow is used.

TikTok data is used only to operate the operator's own TikTok account. It is not sold, not used for advertising, and not used to build profiles of other people. Use of information received from TikTok APIs complies with the TikTok Developer Terms of Service and TikTok's developer policies.

To remove TikTok access: disconnect the account in the tool, and in TikTok go to Settings and remove the app's authorization. You can also write to ssseleniasanchez@gmail.com to request deletion of TikTok data stored by the tool. Content already published on TikTok is not deleted from TikTok by this process; it can be deleted in TikTok itself.

Instagram and Facebook

When the operator connects an Instagram professional account, the tool requests instagram_business_basic (account ID, username, and profile, to show which account is connected) and instagram_business_content_publish (to publish content the operator creates or schedules). Facebook data received through Meta's official OAuth flow is used the same way: to identify the connected account and to publish the operator's content.

Use of information received from Meta APIs (Facebook, Instagram, Threads) complies with the Meta Platform Terms and Developer Policies.

To remove Meta access: disconnect the account in the tool, and in Instagram or Facebook go to Settings → Apps and websites and remove the app. Requesting deletion there, or writing to ssseleniasanchez@gmail.com, causes the tool to erase stored tokens and account data for that connection.

LinkedIn, YouTube, and other networks

For any other network the operator connects, the tool receives only the identifiers, profile information, and publishing permissions granted on that network's official OAuth screen. The data is used only to show which of the operator's accounts is connected and to publish or schedule the operator's content through the official API.

Why this data is used

Only to run the operator's own publishing workflow: connecting her accounts, scheduling and publishing content, showing the status of connections and posts, warning when a connection needs attention, keeping the tool secure, and meeting each network's developer rules. Data is not sold and is not used for advertising.

Who it is shared with

  • Each social network the operator connects, only to carry out the connect or publish actions she requests.
  • GitHub, Inc., which hosts these public legal pages on GitHub Pages.
  • The hosting and storage providers the operator configures for the application and uploaded files.

The tool is not shared with customers, subscribers, or other users.

How it is protected

  • Application traffic is served over HTTPS in production.
  • Social network tokens are encrypted at rest with AES-256-GCM.
  • Passwords are stored only as salted scrypt hashes.
  • Access tokens are not returned to the browser or written to application logs.
  • The tool does not store social network passwords.

This policy does not claim certifications, audits, or other security practices that are not implemented.

How long it is kept

  • Account, media, and content data: while the operator uses the tool, until she deletes it.
  • Tokens: until the operator disconnects the account, the network revokes authorization, or deletion is requested.
  • Expired or closed sessions: deleted automatically.
  • Audit records of connections and deletions: kept so the operator can see what was done and when. They contain no tokens or network identifiers.

How to delete data

Data stored by the tool can be deleted in these ways:

  • Disconnect a social account in the tool. Tokens for that account are erased, scheduled posts for that account are cancelled, and the account stops being available for publishing.
  • From the social network: remove the app in TikTok, Instagram, Facebook, or the equivalent settings of another network. The tool then stops using the tokens. If the network sends a data deletion request, stored tokens and account data for that identity are erased.
  • By email: write to ssseleniasanchez@gmail.com and ask for stored data to be deleted. You can also use the contact form on iamselenia.com.

Content already published on a social network is not deleted from that network. It can be deleted in the network itself.

Children
