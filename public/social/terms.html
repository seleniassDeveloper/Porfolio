These terms describe Social Publishing Platform, a personal, private tool operated by Selenia Sanchez. The tool is used only by the operator to connect and manage her own social media accounts. It is not offered to the public, does not accept public registration, is not sold, and has no subscriptions, billing, or commercial plans.

The tool

The tool connects the operator's own accounts through each network's official OAuth flow and lets her create, schedule, or publish content through each network's official API. It includes a calendar, scheduled publishing, and a media library. Which features work depends on each network, the type of account, and the permissions granted. The tool never asks for social network passwords.
